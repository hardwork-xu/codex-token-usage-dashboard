          默认估算：如果相同模型和已记录 Token 用量改用 API Standard，按已观察到的缓存命中比例需要多少费用。也可选择原有 Credit 折算或自定义单价。

          默认 $0.04 / Credit，即 2,500 Credits = $100。仅用于本地 Credit 费用估算，不影响官方余额折算或 API 等价费用。

          只改变本地购买 Credits 的估算场景，不修改 Codex 的实际速度、官方记录或余额。API 始终按 Standard；Ultra 思考强度与速度档位不同。

          参考汇率，可修改。美元换算值固定为 1；页面不会自动查询或更新汇率。

          按总 Token 统一折算，不区分模型、缓存或输出费率。数值使用上方的货币单位。

          填写订阅每月续订的日期。周期从当天开始，到下次续订日前结束；当月没有这一天时按月末计算。这里只调整统计范围，不会修改你的订阅。

          API 等价费用 = 各模型的普通输入、缓存输入、输出分别乘以 API 单价后相加，再换算货币。不使用每 Credit 的换算比例。
